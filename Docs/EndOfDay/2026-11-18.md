## Work in detail

### CLAUDE.md and ways of working (main)
- **Working rules:** C++ for gameplay, Blueprints only for wiring and tuning. Epic coding
  standard, modular components, delegates and interfaces, well-commented and configurable code,
  custom editors in a separate editor module. Ask before editing existing source files. One branch per feature.
- **Project overview:** jam dates, theme, game pitch (sinking ship, monster, repair, escape), the
  three-developer team coming from Unity.
- **Teaching:** relate Unreal and C++ to Unity/C#, and don't simplify code for learners.
- **Inspirations:** Alien: Isolation, SOMA, Resident Evil 7, Subnautica, Still Wakes the Deep.
- **Plan paper trail:** every plan is saved as versioned files in `Docs/Plans/<date>-<topic>/`.
- **Details panel rule:** every class lists its own categories in `PrioritizeCategories` (no
  spaces in names) and actor base classes hide engine categories that never apply.
- `claude-coding-rules` is a long-lived branch for CLAUDE.md edits, kept level with `main`.

### Survivor player character (`player-character` branch, not merged)
- **`ASurvivorCharacter`:** first person, no jumping, crouch (toggle) with a smooth camera blend,
  slow walk with a stamina-limited sprint.
- **Components:** `UStaminaComponent` (timer-driven, exhaustion until 50% recovered),
  `USurvivorMovementComponent` (sprint via `GetMaxSpeed`), `UInteractionComponent` (traces on a
  new `Interaction` trace channel), `UItemHolderComponent` (one item in hand), `UInventoryComponent` (3 slots).
- **Items:** `AHeldItem` base class, `UItemDefinition` data asset, `IInteractable` interface.
  Picking something up stows the held item, but a **lit flare is dropped**, and so is any item when the inventory is full.
- **Flare (`AFlareItem`):** lit with LMB, burns for 30 s with flicker and a fade at the end, can be
  thrown and keeps burning, auto-drops and is cleaned up when burnt out.
- **Camera feel:** `USurvivorCameraModifier` adds head-bob, breathing (heavier at low stamina),
  strafe roll and look lag. Players can toggle it with the console command `SetCameraMotionEnabled 0`.
- **HUD:** `UI_SurvivorHUD` shows stamina, the interaction prompt, the held item, the flare timer and the inventory row.
- **Content:** input actions and `IMC_Survivor`, the `BP_Survivor*` Blueprints, `DA_Flare`,
  `BP_Flare`, and `Lvl_ShipTest` (copy of the horror grey-box with 5 flares and a crouch beam).
- **Fix after the first playtest:** throwing while sprinting flew too far. Items now keep 20% of the
  player's velocity (`InheritedVelocityScale` on the item definition).

### Editor tooling
- New `EndlessOceanEditor` module (editor-only). `FPrioritizedCategoriesCustomization` puts a
  class's own categories directly under Transform in the Details panel. It turns on automatically
  for any class that declares `PrioritizeCategories`.
